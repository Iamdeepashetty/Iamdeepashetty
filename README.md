RFCOE Analog IC Design Hackathon 2026

Active-Inductor-Based Low Noise Amplifier (LNA)

🏆 Achievement: 4th Prize – ₹5,000

An Analog IC Design project developed for the RFCOE Analog IC Design Hackathon 2026, organized by SASTRA University.

📌 Project Overview

This project focuses on the design and simulation of a Low Noise Amplifier (LNA) using an active inductor instead of a conventional physical inductor.

The objective was to design an RF amplifier that meets the specified requirements for noise performance, power gain, linearity, impedance matching, and power consumption.

The circuit was designed and simulated using Cadence Virtuoso, followed by RF performance analysis and optimization.

🎯 Problem Statement

Design a Low Noise Amplifier (LNA) according to the given RF specifications, using an active inductor. The use of a physical inductor is not permitted.

⚙️ Design Specifications

Parameter| Specification
Noise Figure (NF)| < 2 dB
Power Gain| > 10 dB
Operating Frequency| 1–2 GHz
Linearity| Higher IIP3
Input/Output Impedance| 50 Ω
Power Consumption| < 25 mW
Gain Flatness| ±0.5 dB
Operating Voltage| 5 V
Inductor Type| Active Inductor

🔬 Our Work

Our team designed and simulated an active-inductor-based Low Noise Amplifier using Cadence Virtuoso.

The project involved:

- Designing an LNA using an active inductor.
- Analyzing the amplifier's RF performance.
- Simulating the circuit against the given specifications.
- Evaluating noise figure, power gain, impedance matching, and linearity.
- Optimizing the circuit to improve performance.
- Analyzing simulation results against the design requirements.
